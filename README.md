

# 🌐 One Page - Landing Page Moderna

## 🧠 Sobre o projeto

O **One Page** é uma landing page desenvolvida com o objetivo de apresentar conteúdos de forma **simples, direta e visualmente atrativa**, utilizando o conceito de **página única (Single Page Application - SPA estática)**.


## 🎯 Objetivos

* Criar uma interface moderna e intuitiva
* Aplicar boas práticas de HTML e CSS
* Trabalhar organização de layout com Flexbox
* Desenvolver um projeto reutilizável para portfólio
* Simular uma landing page real de produto/tecnologia

---

## 🛠️ Tecnologias utilizadas

### 🔹 Front-end

* **HTML5**

  * Estrutura semântica
  * Organização por seções (`header`, `section`, `footer`)
* **CSS3**

  * Flexbox para layout
  * Gradientes (`linear-gradient`)
  * Responsividade básica
  * Estilização moderna (bordas, sombras, espaçamentos)

### 🔹 Design

* Paleta com tons escuros (dark mode)
* Destaques em gradiente (azul + roxo)
* Interface inspirada em produtos de tecnologia/IA

---

## 🧩 Estrutura da página

A aplicação segue o padrão de **seções organizadas verticalmente**:

### 🔸 Header

* Logo do projeto
* Menu de navegação
* Botão de ação (CTA)

### 🔸 Seção Principal

* Imagem ou ilustração (ex: robô/IA 🤖)
* Título chamativo
* Texto descritivo
* Botão de ação

### 🔸 Seção de Aplicações / Features

* Cards informativos
* Ícones + descrição
* Layout em destaque

### 🔸 Seção de Conteúdo

* Explicações adicionais sobre o tema
* Textos organizados e centralizados

### 🔸 Footer

* Logo
* Direitos autorais
* Redes sociais (Instagram, LinkedIn, GitHub)

## 🚀 Como executar o projeto

### ✔️ Pré-requisitos

Você só precisa de um navegador:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

---

### ▶️ Passo a passo

1. Clone o repositório:

```bash
git clone https://github.com/EmillySRamalho/One-Page
```

2. Acesse a pasta:

```bash
cd One-Page
```

3. Execute o projeto:

* Abra o arquivo `index.html` no navegador
