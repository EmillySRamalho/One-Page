# One Page - Inteligência Artificial 🤖✨

Projeto de uma landing page sobre Inteligência Artificial, apresentando conceitos, aplicações e benefícios da IA no dia a dia.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Gradientes
- Responsividade básica

## 📌 Sobre o projeto

A página apresenta uma interface moderna com tema futurista, utilizando cores em tons de azul, roxo e fundo escuro. O conteúdo aborda:

- O que é Inteligência Artificial
- Machine Learning
- Deep Learning
- Automação
- Chatbots
- Reconhecimento facial
- Carros autônomos
- Assistentes virtuais
- Benefícios da IA

## 💻 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/EmillySRamalho/One-Page.git
````

2. Acesse a pasta do projeto:

```bash
cd One-Page
```

3. Abra o arquivo `index.html` no navegador.

## 📁 Estrutura do projeto

```bash
One-Page/
├── img/
├── index.html
└── styles.css
```
